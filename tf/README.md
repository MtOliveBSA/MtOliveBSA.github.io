# Public Tournament Website

GitHub Pages frontend for the reusable Tournament App.

## Includes

- Teams display
- Team logos
- Mobile responsive UI
- Public standings
- Bracket display
- Games/results display

## Setup

1. Deploy your Apps Script backend as a Web App.
2. Copy the Web App URL.
3. Open `config.js`.
4. Replace `PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE` with the Web App URL.
5. Upload these files to a GitHub repository.
6. Enable GitHub Pages from the repository settings.

## Optional Tournament Lock

Set `TOURNAMENT_SLUG` in `config.js` to match the `PublicSlug` value from the `Tournaments` sheet.
